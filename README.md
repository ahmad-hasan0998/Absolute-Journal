# Absolute Journal 🎬

A full-stack mobile media tracking application designed to help users seamlessly manage, track, and discover movies and TV shows.

## 🚀 Features

* **Dynamic Media Discovery:** Fetches real-time movie and TV show data using external media APIs.
* **Secure Data Storage:** Utilizes Firebase for secure, real-time database management and user authentication.
* **Scalable Architecture:** Built with a clean architecture utilizing Provider for efficient state management.
